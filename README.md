# TaskPulse

TaskPulse é uma aplicação de demonstração com Next.js e Tailwind CSS que consome uma API pública para listar tarefas de forma leve e responsiva.

> Nome literal: taaskpulse

## Descrição

A aplicação faz requisições a uma API externa e renderiza uma lista de tarefas, mostrando como montar uma interface moderna com Next.js, React e Tailwind CSS. É ideal como base para um portfólio ou protótipo de integração de APIs.

## Funcionalidades

- Busca tarefas de uma API pública.
- Exibe tarefas em uma lista simples e elegante.
- Estrutura moderna com Next.js 14 e Tailwind CSS.

## Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) - Framework React para renderização híbrida e desempenho.
- [React](https://react.dev/) - Biblioteca para construção de interfaces.
- [Tailwind CSS](https://tailwindcss.com/) - Estilização utilitária rápida.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) - API pública de teste e prototipação.

## Como Executar

1. Clone este repositório:
    ```bash
    git clone https://github.com/seu-usuario/req-next.git
    ```

2. Entre na pasta do projeto:
    ```bash
    cd req-next
    ```

3. Instale as dependências:
    ```bash
    npm install
    ```

4. Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

5. Abra [http://localhost:3000](http://localhost:3000) no navegador.
